# Hangman Game

## Project Description

This project is a simple text-based Hangman game developed using Python.

The player has to guess the hidden word one letter at a time. The computer randomly selects a word from a list of 5 predefined words.

## Features

- Randomly selects a word from 5 predefined words.
- Allows the player to guess one letter at a time.
- Displays correctly guessed letters.
- Allows a maximum of 6 wrong guesses.
- Displays the final result.
- Simple and easy-to-use text-based game.

## Technologies Used

- Python

## Python Concepts Used

- Random module
- Lists
- Strings
- While loop
- For loop
- If-else statements
- Input and Output

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

python hangman.py

5. Enter one letter at a time to guess the hidden word.

## Game Rules

- The computer selects one word randomly.
- The player guesses one letter at a time.
- Correct guesses reveal the letters.
- Wrong guesses increase the wrong guess count.
- The player gets a maximum of 6 wrong guesses.
- The player wins by guessing the complete word.
